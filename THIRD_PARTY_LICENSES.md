# Third-party licences

Audit date: 2026-11-07. This file covers the components distributed with or required to
build the project. It is a factual inventory, not legal advice.

## Runtime

The application has **no third-party runtime dependencies**. It imports only modules from
the Python standard library (`csv`, `sqlite3`, `decimal`, `hashlib`, `hmac`, `secrets`,
`http.server`, `urllib`, `email`, `html`, `unittest` and related modules) and its own
`student_spending` package.

No JavaScript library, CSS framework, web font, analytics SDK, icon pack, charting
library or JSON schema validator is bundled. The HTML, CSS and SVG are authored in this
repository. The only image is `src/student_spending/assets/plan-it-logo.jpg`, created for
this project and covered by the repository's MIT licence.

| Component | Version constraint | Licence | Purpose | Distributed in the runtime? |

## Data

`data/raw/*.csv` is generated by `src/student_spending/synthetic.py` and describes no real
people, institutions, accounts, cards or payments. It is covered by the repository's MIT
licence.

## How to re-audit

```powershell
python -m pip check
python -m pip list --format=freeze
python -m compileall -q src
```

Because there are no runtime requirements, `pip check` should report no broken
requirements. Any new dependency must be added here with its licence, purpose and whether
it ships to users before it is merged.
